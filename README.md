# tuneref

Tune CSV/TSV ref tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/tuneref/

## Install / run

```bash
git clone https://github.com/theworker02/tuneref.git
cd tuneref
node src/cli.js
node --test
```
